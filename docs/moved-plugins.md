# Plugins that left this repository

A plugin removed from this marketplace takes its skills and their rule IDs with it. Writing rule 6 (CONTRIBUTING.md) still holds for every rule here: an ID is never reused, and a citation of an old ID finds the rule at the place below, under the same ID. `scripts/check_repo.py --base` accepts the removal of a plugin's rule IDs only when the plugin is listed here.

- `mulesoft`: moved to devFoundry (brunosouzas/devfoundry-plugins, marketplace `devfoundry`), plugin `mule-engineering`, with the same IDs: skills `mulesoft` (now `mule-app` and `apikit`), `dataweave`, `munit`, `mule-sdk`; its EIP reference is devFoundry's `docs/backlog/eip-from-agent-skills.md`. The naming rules (FLOW-5, FLOW-6, DW-3) and the deploy rules (PLAT-1, PLAT-3 to PLAT-5) were not carried over: they belong to a project's or a company's own conventions and delivery.
- `api`: moved to devFoundry, plugin `api-contracts`, skill `api-contract`, with the same RES, CON and APISEC IDs.
